# Summary

The ominous mask of the infamous Darth Revan.

Should be scaled to be roughly the proper size
Modeled it based on some screenshots from Bioware's Star Wars: The Old Republic

I loved KoTOR when it came out and I really like what Bioware did with Revan's aesthetics, so I thought I'd try my hand at some less-than-linear modeling with some new software. Comments and criticisms are welcome! I'm a 3D printing hobbyist looking to improve :)
